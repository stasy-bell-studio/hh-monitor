# Portraits — профили идеальных кандидатов

Каждый JSON-файл в этой директории описывает профиль («портрет») для одной вакансии. Портрет задаёт критерии оценки резюме: ключевые слова, опыт, зарплатную вилку и т.д.

## Поля

| Поле | Тип | Назначение |
|------|-----|-----------|
| `position_code` | string | Уникальный код должности (соответствует `searches.position_code`) |
| `position_name` | string | Читаемое название |
| `title_keywords` | string[] | Слова в текущем title резюме (+25 при совпадении хотя бы одного) |
| `experience_keywords` | string[] | Слова в описании опыта работы (+15) |
| `min_total_months` | int | Минимум опыта в месяцах (+10 если выше; −10 если ниже) |
| `preferred_total_months` | int | Желаемый опыт (+20 если выше) |
| `max_salary` | int \| null | Порог зарплаты (+10 если ≤ или null; −15 если выше) |
| `preferred_education_levels` | string[] | id-уровней образования из /dictionaries (+5) |
| `preferred_areas` | string[] | Города из /areas (+10) |
| `age_range` | [int,int] \| null | Диапазон возраста (+5) |

## Как HR обновляет портрет

1. Откройте нужный JSON-файл, например `portraits/branch_director.json`.
2. Измените нужные значения (ключевые слова, пороги опыта, зарплату и т.д.).
3. Сделайте `git commit` с описанием изменений.
4. При следующем запуске парсера новые правила применятся автоматически.

Веса правил калибруются совместно с HR-командой. Текущие значения — PoC-приближение.
